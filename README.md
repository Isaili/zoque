## 🟠 Sobre el proyecto

Landing page oficial de **Auto Transportes Zoque**, empresa de transporte foráneo con base en **Copainalá, Chiapas**. El sitio transmite la identidad de marca *"Orgullosamente Zoques"* y permite a los pasajeros consultar destinos, horarios y precios, además de iniciar el proceso de reserva de viaje.

> 🧡 Desarrollado por **[Softvana](https://isaili.github.io/CODEX_SOFTVA/)**

<br>

## 🗺️ Secciones del sitio

| Sección | Descripción |
|---|---|
| 🏠 **Hero** | Presentación de marca + CTA "Reserva tu viaje" |
| 🧑‍🤝‍🧑 **Nosotros** | Seguridad, atención personalizada y compromiso con Chiapas |
| 📍 **Destinos** | Copainalá, Tuxtla Gutiérrez, Tecpatán, Coapilla, Ocotepec, San Fernando y más |
| 🕓 **Horarios y rutas** | Tabla con salida, llegada, frecuencia y precio |
| 🚐 **Flotilla** | Presentación de las unidades |
| 💳 **Compra de boletos** | Flujo paso a paso con pagos vía **Stripe** |
| 💬 **Testimonios** | Experiencias de pasajeros |
| 🗺️ **Mapa de cobertura** | Rutas dentro de Chiapas |
| 🎉 **Promociones** | Ofertas y descuentos vigentes |
| ❓ **FAQ** | Preguntas frecuentes |
| ✉️ **Contacto** | Formulario de dudas y reservas |

## 📦 Instalación

```bash
git clone <https://github.com/Isaili/zoque.git>
cd auto-transportes-zoque
npm install
```

## 🚀 Desarrollo local

```bash
npm run dev
```

Abre 👉 [http://localhost:3000](http://localhost:3000)

## 🏗️ Build de producción

```bash
npm run build
npm run start
```
